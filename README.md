# Статическая климатическая база

Карта читает климат только из `data/climate/<ISO3>.json`. Во время работы страницы внешние климатические API не вызываются.

## Сборка данных

Требуется Node.js 18+.

```bash
npm run build:climate
```

Дополнительные npm-зависимости сборщику больше не нужны.

Скрипт один раз скачивает:

- Natural Earth — страны и значимые города;
- WMO Climatological Standard Normals 1991–2020 (`TAVG`, `TMIN`, `TMAX`, min24 composites);
- CRU TS 4.09 — официальные ASCII `.dat.gz` за 1991–2000, 2001–2010 и 2011–2020 для `TMP`, `TMN`, `TMX`.

CRU-файлы читаются потоково. Для городов без близкой полной WMO-станции скрипт выбирает ближайшую сухопутную ячейку сетки CRU 0.5° и сам считает 12 среднемесячных норм за 1991–2020.

После выполнения создаются файлы `data/climate/AAA.json`, `data/climate/ALB.json`, ..., а также `manifest.json`.

`KAZ.json` не перезаписывается: для Казахстана сохраняется уже вручную проверенный набор Казгидромет/WMO/CRU.

Кэш исходных файлов находится в `.cache/climate-build`. Старые файлы `cru-mean.nc`, `cru-min.nc`, `cru-max.nc` от предыдущего генератора можно удалить — новая версия их не использует.

После сборки страница доступна по адресу:

`http://localhost:3000`
